# Archivos de CADe_SIMU

Aquí van los archivos de CADe_SIMU de cada ejercicio, cuando estén probados
(`L0_lampara`, `L1_marcha_paro`, `L2_dos_puntos`, `L3_inversion`, `L4_estrella_triangulo`,
`L5_secuencial`).

No se generan automáticamente: CADe_SIMU guarda los circuitos en su propio formato. Para
armarlos usa `docente/RGIM_Guia_CADeSIMU_Paso_a_Paso.docx`. Esa guía lista los componentes
con su nombre, el orden de armado y la tabla de estados para verificar cada ejercicio.
